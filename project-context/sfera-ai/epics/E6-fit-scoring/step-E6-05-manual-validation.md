# Шаг E6-05 — ручной прогон и сверка с HR

**Статус:** TODO
**Слой:** QA · **Зависит от:** E6-04

## Цель

10–20 реальных кандидатов прогнаны через Fit scoring, HR подтверждает адекватность
скоров/рекомендаций (не автоматическая метрика — субъективная сверка владельцем/HR).

## Что сделать

1. Выбрать 10–20 кандидатов с разной полнотой данных (`data_completeness` разный) на
   одном `course` из пилота E6-04.
2. Прогнать реальный Fit-вызов, собрать результаты в читаемом виде (CLI-вывод или
   CSV) для сверки HR.
3. Зафиксировать расхождения (если есть) — отдельный документ или запись в `04_STATE.md`
   журнале, не блокирует эпик, если расхождения объяснимы.

## Файлы

- `src/sfera_ai/cli/run_fit_scoring_sample.py` — ручной прогон
- нет автотеста — это ручная валидационная сессия

## Критерии готовности (DoD)

- [ ] 10–20 прогонов выполнены, результаты показаны HR/владельцу
- [ ] Явное подтверждение «адекватно» получено (или список найденных проблем передан
      на доработку промпта — тогда шаг не закрывается)

## Как проверить

```bash
uv run python -m sfera_ai.cli.run_fit_scoring_sample --course-id <id> --limit 20
```

## Как отметить выполнение

1. Впиши результат в журнал ниже. 2. Статус → `DONE`. 3. Обнови `04_STATE.md` (эпик E6
   → DONE, следующий — E7 или E8 по графу зависимостей).
