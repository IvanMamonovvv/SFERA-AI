## Цель

При открытии модалки «Обработка кандидатов» HR видит «Осталось обработать: N» либо
«Обработка завершена» — без polling/realtime, только на момент открытия.

## Что сделать

1. Запрос прогресса (новый метод в `candidate-screening-repository.ts`, зовёт прокси
   E25-02) при открытии модалки — вместе с уже существующим запросом списка подходящих
   кандидатов (`fit_score>=60`, E15-03), не отдельным independent-эффектом с своим
   таймингом.
2. Отображение: «Осталось обработать: N» при `remaining>0`, «Обработка завершена» при
   `remaining=0`. Если E25-01 завёл отдельное поле `failed>0` — короткая пометка рядом
   (решить формулировку на этапе реализации, не выдумывать заранее).
3. Без агрессивного polling — данные обновляются только при повторном открытии модалки
   (по аналогии с решением по видео-транскрипту, E14-06).
