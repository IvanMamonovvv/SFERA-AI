# Шаг E17-06 — визуальный стиль карточки как в эталоне РТХ

**Статус:** DONE (код готов, визуальное сравнение с эталоном РТХ на реальных кандидатах — не выполнено)
**Слой:** Backend (PDF-рендер) · **Зависит от:** E17-04, E17-05
**Перед началом:** прочитай `src/sfera_ai/services/export/ai_card.py` целиком,
`src/sfera_ai/services/api_read.py` (функции `resolve_company_slug_for_course`,
строки 29-38, и join `Course`/`Company`). Контекст решения — переписка с владельцем
2026-09-10: эталон — PDF-карточка клиента «РТХ» (файл
`РТХ_менеджер_по_продажам_B2B_клиентский_пакет_2_кандидата_2026 (2).pdf`), точные
цвета/шрифты/координаты вытащены из него через `pymupdf` (см. журнал).

## Цель

Карточка кандидата (`render_ai_card_pdf`) визуально и по структуре совпадает с
эталоном РТХ: те же цвета, размеры шрифта, формат страницы, структура блоков
(синтез вместо сырого дампа фактов, конкретные вопросы вместо общих пробелов).

## Решения владельца (2026-09-10)

1. Брендинг шапки — название заказчика (компании вакансии на платформе), не
   статичное "SFERA". Fallback — `"SFERA"`, если имя компании не резолвится.
2. Возраст/отрасль в шапке — из `age`/`industry` фактов (готово в E17-04).
3. Правая колонка карточки ("Что уточнить") — `interview_questions` вместо `gaps`.
4. `fit_score` в БД/промпте остаётся 0-100 (без изменений) — при рендере делить
   на 10 для отображения, шкала эталона (0-10) — только визуальная, не меняет
   хранение/API.
5. Лексика вердикта — существующий `RECOMMENDATION_RU` ("Явно подходит" и т.п.),
   новый словарь "передавать/не передавать" НЕ заводить.

### `src/sfera_ai/services/export/ai_card.py`
- `FACT_KEY_LABELS_RU` (строки 69-84) — добавить `"age": "Возраст"`,
  `"industry": "Отрасль"`.
- Цветовые константы (строки 43-59) — привести к токенам из таблицы выше
  (`_COLOR_STRENGTHS`/`_COLOR_GAPS` схлопнутся в один `_COLOR_SECTION_TITLE`,
  добавить `_COLOR_BULLET_LEFT`, `_COLOR_BULLET_RIGHT`).
- `_strip_block` (строки 138-155) — bg → `#193a63`; принимает `client_name: str`
  параметром вместо статичного `"КАРТОЧКА КАНДИДАТА"`.
- `_meta_bar` (строки 167-185) — добавить возраст в 1-ю ячейку
  (`"{city} · {age} лет"`), отрасль во 2-ю ячейку вместе с сегментом; добавить
  `GRID` в `TableStyle` (сейчас рамок нет).
- `_recommendation_block` (строки 188-203) — без структурных изменений, текст
  дополнить кратким перечислением тем из `interview_questions` (как в эталоне).
- `_two_col_block` (строки 206-223) — правая колонка: `gaps` → `interview_questions`;
  заголовки обеих колонок — один цвет `#193a63`; буллеты — квадратный маркер вместо
  `&bull;`, разного цвета для колонок (через `<font color="...">■</font>` в тексте
  параграфа, либо кастомный flowable).
- `_platform_block` (строки 233-249) — переписать: вместо дампа `facts`
  (`_fact_line`, строки 226-230, станет неиспользуемым) — буллет-список из
  `current.summary` (список строк — готово в E17-05) + при наличии
  `current.contradictions` жирная строка `"Важно: ..."` цветом `#a34b3f`.
- `_score_color` (строки 273-282) — убрать пороговую логику, всегда возвращать
  `#087486`; обработать `None`/"не оценено" без `float()`-исключения.
- `_criteria_scores_table` (строки 285-302) — формат значения `"{X,X}/10"` (запятая
  вместо точки), `None` → `"не оценено"`.
- Итоговая строка (строка 362) — заменить на
  `f"<b>Итог: {fit_score/10:.1f}/10 - предварительно, {recommendation_ru}.</b> <i>Достоверность оценки: {confidence_ru}.</i>"`.
- `SimpleDocTemplate` (строки 337-340) — `pagesize=A4` → `pagesize=letter`
  (`from reportlab.lib.pagesizes import letter`).
- `ParagraphStyle` (строки 88-102) — уменьшить `fontSize` под таблицу токенов выше.
- `render_ai_card_pdf` (строка 305+) — принять/зарезолвить имя заказчика через
  `resolve_company_name_for_course`, прокинуть в `_strip_block`.
