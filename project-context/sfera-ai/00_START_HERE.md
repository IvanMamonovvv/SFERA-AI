## Что мы делаем

Отдельный сервис AI-анализа кандидатов для платформы SFERA — читает данные платформы
(кандидаты, ответы, резюме, видео) напрямую из той же PostgreSQL, что использует
`sfera_backend` (read-only, без Django ORM, через SQLAlchemy reflection), пишет только
в свои 7 таблиц (`ai_*`). Оценивает соответствие кандидата вакансии (`Fit`), копит
факты о кандидате отдельно от скора, учится на фидбеке менеджера по вакансии.
